Required, and it takes a minute

GoodBit records nothing. OBS does.

GoodBit is a companion to OBS. OBS keeps the last thirty seconds of your game in memory and writes them to a file when you press a key. GoodBit watches the folder those files land in: it sorts them by game, measures where the loud part was, and gives you somewhere to trim, tag and share them.

Three things have to be true before a clip appears in your library, and the third is the one nobody finds on their own.

  1. The replay buffer is running, and a key saves it.
  2. OBS writes where GoodBit watches, the same folder for both.
  3. Each clip lands in a folder named after the game. OBS cannot do this. Its filename format takes the clock and the video settings and nothing else, so without help every clip lands in one folder and your whole library looks like a single game.

One button, and a list of what it changes

In the app: Settings → Recording, or the first run, which walks the same ground. There are two routes inside it. Quick setup takes your main screen, thirty seconds, F8, your usual sound and a folder per game, and shows you the four lines it has decided. Step by step asks about each of them.

OBS itself is part of it. With no OBS on the machine, the first step installs it from the OBS project's own release: Windows asks for permission, and nothing else needs clicking. It also brings its own Python for the sorting script, into its own folder, because OBS only loads Python 3.10 to 3.12 and says so nowhere except its log.

Tick what you want it to do. The link at the bottom opens the app with these chosen.

Set it up in GoodBit

Opens the app and shows you the changes. Nothing is written until you press Apply there.

What it actually writes

A profile folder of its own and a scene collection of its own, both called GoodBit, plus two keys in OBS's own config: where Python is, and the flag that stops OBS opening its auto-configuration wizard over the settings this has just chosen. It never edits a profile you made, never switches the profile OBS opens with, and keeps a record of every key it set so it can put things back.

The profile carries the resolution and frame rate of the screen you picked, at full size, and its colour. If that screen is in HDR mode it records in HDR with a ten bit encoder, because recording an HDR display as standard colour clips the highlights in the file itself and nothing afterwards can bring them back. The scene has game capture on top, the screen underneath for anything that is not a fullscreen game, and whichever audio devices you chose, each on its own fader.

It refuses to write anything while OBS is open, and says so. OBS holds its settings in memory and rewrites the whole file when it saves, so an edit made underneath it is thrown away rather than merged.

    Install OBS

    Free and open source, from obsproject.com. On Windows you can also run winget install -e --id OBSProject.OBSStudio.

    Open it once after installing. It writes its configuration on first run, and nothing below exists until it has.

    One folder, used by both

    In OBS: Settings → Output → Recording → Recording Path. In GoodBit: Settings → App → Clips folder. Point them at the same place.

    GoodBit reads <that folder>/<Game name>/clip.mp4. The folder name is the game name, which is what the last step is for.

    Turn on the replay buffer

    Settings → Output. In Simple mode, tick Enable Replay Buffer and set Maximum Replay Time to about 30 seconds. That is how much of the past OBS keeps in memory, ready to write out.

    Then press Start Replay Buffer in the main window, or pass --startreplaybuffer when launching OBS so it is always on.

    Bind a key to Save Replay

    Settings → Hotkeys → Save Replay. F8 is a common choice. This is the key you press after something good happens.

    It works while the game has focus, which is the whole point, so pick something no game uses.

    Capture the game

    Add a Game Capture source and leave its mode on Capture any fullscreen application. It then needs no per-game setup and no choice of monitor.

    Add a Desktop audio source too, or your clips are silent. If a game refuses to be captured this way, a Display Capture source underneath it is the usual fallback.

    A folder per game

    This is the part OBS cannot do. Its filename format has 23 tokens and every one of them is a clock, a resolution or a frame rate; there is no token for the game you are playing. Typing %GAME silently writes the literal text GAME into every filename.

    The answer everyone uses is Smart Replays, an OBS script by qvvonk, AGPL-3.0. It watches which application is in front when you press the key and moves the saved clip into a folder named after it.

    1. Install Python between 3.10 and 3.12, with the tcl/tk option ticked in the installer. Not newer: OBS refuses to load 3.13 and reports that in its log and nowhere else. The script imports tkinter at startup, so a build without tcl/tk does not load at all.
    2. In OBS: Tools → Scripts → Python Settings, and point it at that Python folder. OBS runs no script at all until this is set.
    3. Download smart_replays.py from its repository and add it under Tools → Scripts with the + button.
    4. Set Base path for clips to the same folder as before. It must be on the same drive as OBS's recording path, because the script moves files rather than copying them.
    5. Leave Sort clips into folders ticked. That is the whole point.
    6. Add an alias per game so the folder gets a name a person would recognise. The format is C:\path\to\game > Game Name, and a folder works as well as an executable, so one line covers whatever the game's exe is called.

    Two things worth knowing before you rely on it. Its Restart every option is on by default and has an open crash report against it, so consider setting it to 0. And it reads which process is in front by opening a handle to it, so if you play something with strict anti-cheat and would rather it did not, its name from the current scene mode never touches another process.

    Check it works

    Start a game, press your key, and alt-tab. A folder named after the game should appear in your clips folder, with one file in it, and GoodBit should already be showing it: it watches that folder whether or not its window is open.

    If nothing appears, open Settings → Recording in GoodBit. It reads OBS's own configuration and names the setting that is wrong, in a sentence, rather than leaving you to guess which of the six above it was.
